## `fleet-top` を次にする理由

- **実際に踏んだ穴**: 2026-09-01 に統合リナが「どの艦が kit に載っているか」「stale な枝は」を何度も手で回した。
  `gh api` は直列で 1 本 0.67 秒（実測）。フリート分（42 リポ × 3 種）で約 84 秒。
  **84 秒かかるコマンドは打たれない**。weekly-audit が 4 日間 0 艦だったのも「見るのが高いから誰も見なかった」から
- **実測できる**: 手元に 59 の git リポがある。並列化の効果は試作 1 本で数字になる
- **1 本で閉じる**: 「艦隊の状態を 1 画面で」は問題として明快

⚠️ **「並列化で 3 秒」は想定であって実測ではない。** 試作で測るまで README に書かない。
